<Question>
A class of $20$ students has an average test score of $80$. A different class of $30$ students has an average test score of $90$. What is the average test score of all $50$ students combined?
</Question>

<Choices answer="D">
<Choice label="A">84</Choice>
<Choice label="B">85</Choice>
<Choice label="C">85.5</Choice>
<Choice label="D">86</Choice>
<Choice label="E">87</Choice>
</Choices>
</QuestionPane>

<ExplanationPane>
<Explanation>
<SolutionStep number={1} title="Find each class's total score">
Class 1: $20 \times 80 = 1600$. Class 2: $30 \times 90 = 2700$.
</SolutionStep>

<SolutionStep number={2} title="Combine the totals">
Combined total: $1600 + 2700 = 4300$, over $20 + 30 = 50$ students.
</SolutionStep>

<SolutionStep number={3} title="Compute the combined average">
$\frac{4300}{50} = 86$.
</SolutionStep>
</Explanation>
