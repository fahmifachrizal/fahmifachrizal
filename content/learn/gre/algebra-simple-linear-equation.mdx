<Question>
If $5x - 3 = 2x + 12$, what is the value of $x$?
</Question>

<Choices answer="C">
<Choice label="A">3</Choice>
<Choice label="B">4</Choice>
<Choice label="C">5</Choice>
<Choice label="D">6</Choice>
<Choice label="E">7</Choice>
</Choices>
</QuestionPane>

<ExplanationPane>
<Explanation>
<SolutionStep number={1} title="Move variable terms to one side">
Subtract $2x$ from both sides: $5x - 2x - 3 = 12$, which simplifies to $3x - 3 = 12$.
</SolutionStep>

<SolutionStep number={2} title="Isolate x">
Add 3 to both sides: $3x = 15$. Divide by 3: $x = 5$.
</SolutionStep>

<SolutionStep number={3} title="Check">
Substituting back: $5(5) - 3 = 22$ and $2(5) + 12 = 22$. Both sides match, so $x = 5$.
</SolutionStep>
</Explanation>
