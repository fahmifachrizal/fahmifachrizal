<Question>
A value of $200$ is increased by $20\%$ and then the result is decreased by $25\%$. What is the final value?
</Question>

<Choices answer="B">
<Choice label="A">170</Choice>
<Choice label="B">180</Choice>
<Choice label="C">190</Choice>
<Choice label="D">200</Choice>
<Choice label="E">210</Choice>
</Choices>
</QuestionPane>

<ExplanationPane>
<Explanation>
<SolutionStep number={1} title="Apply the 20% increase">
$200 \times 1.2 = 240$.
</SolutionStep>

<SolutionStep number={2} title="Apply the 25% decrease">
$240 \times (1 - 0.25) = 240 \times 0.75 = 180$.
</SolutionStep>

<SolutionStep number={3} title="State the result">
The final value is $180$. Note that a $20\%$ increase followed by a $25\%$ decrease does not return to the original value, since the percentages apply to different base amounts.
</SolutionStep>
</Explanation>
</ExplanationPane>
