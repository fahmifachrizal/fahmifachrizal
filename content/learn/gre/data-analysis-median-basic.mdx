<Question>
What is the median of the data set $\{4, 8, 8, 10, 15\}$?
</Question>

<Choices answer="B">
<Choice label="A">4</Choice>
<Choice label="B">8</Choice>
<Choice label="C">9</Choice>
<Choice label="D">10</Choice>
<Choice label="E">15</Choice>
</Choices>
</QuestionPane>

<ExplanationPane>
<Explanation>
<SolutionStep number={1} title="Check that the data is sorted">
The values $4, 8, 8, 10, 15$ are already listed in increasing order.
</SolutionStep>

<SolutionStep number={2} title="Locate the middle value">
There are 5 values, so the median is the 3rd value in the sorted list.
</SolutionStep>

<SolutionStep number={3} title="Identify the median">
The 3rd value is **8**, choice **B**.
</SolutionStep>
</Explanation>
