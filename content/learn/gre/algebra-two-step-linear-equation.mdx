<Question>
If $5x + 7 = 3x + 19$, what is the value of $x$?
</Question>

<Choices answer="C">
<Choice label="A">4</Choice>
<Choice label="B">5</Choice>
<Choice label="C">6</Choice>
<Choice label="D">7</Choice>
<Choice label="E">8</Choice>
</Choices>
</QuestionPane>

<ExplanationPane>
<Explanation>
<SolutionStep number={1} title="Move variable terms to one side">
Subtract $3x$ from both sides: $5x - 3x + 7 = 19$, which gives $2x + 7 = 19$.
</SolutionStep>

<SolutionStep number={2} title="Isolate the variable">
Subtract $7$ from both sides: $2x = 12$, so $x = 6$.
</SolutionStep>

<SolutionStep number={3} title="Verify">
Substituting $x = 6$: left side $= 5(6) + 7 = 37$, right side $= 3(6) + 19 = 37$. Both sides match, confirming $x = 6$, choice **C**.
</SolutionStep>
</Explanation>
</ExplanationPane>
</QuestionLayout>
