<Question>
$x$ is a real number.

**Quantity A:** $(x - 1)^2$

**Quantity B:** $x^2 - 1$
</Question>

<Choices answer="D">
<Choice label="A">Quantity A is greater</Choice>
<Choice label="B">Quantity B is greater</Choice>
<Choice label="C">The two quantities are equal</Choice>
<Choice label="D">The relationship cannot be determined from the information given</Choice>
</Choices>
</QuestionPane>

<ExplanationPane>
<Explanation>
<SolutionStep number={1} title="Expand Quantity A">
$(x - 1)^2 = x^2 - 2x + 1$.
</SolutionStep>

<SolutionStep number={2} title="Find the difference between the quantities">
Quantity A $-$ Quantity B $= (x^2 - 2x + 1) - (x^2 - 1) = -2x + 2 = 2(1 - x)$.
</SolutionStep>

<SolutionStep number={3} title="Test values of x">
If $x = 0$: the difference is $2(1) = 2 > 0$, so A is greater. If $x = 2$: the difference is $2(-1) = -2 < 0$, so B is greater. If $x = 1$: the difference is $0$, so the quantities are equal.
</SolutionStep>

<SolutionStep number={4} title="Draw the conclusion">
Since the comparison changes depending on the value of $x$, the relationship cannot be determined from the information given.
</SolutionStep>
</Explanation>
</ExplanationPane>
</QuestionLayout>
