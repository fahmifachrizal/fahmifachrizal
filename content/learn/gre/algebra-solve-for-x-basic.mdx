<Question>
If $3x + 7 = 22$, what is the value of $x$?
</Question>

<Choices answer="C">
<Choice label="A">3</Choice>
<Choice label="B">4</Choice>
<Choice label="C">5</Choice>
<Choice label="D">6</Choice>
<Choice label="E">7</Choice>
</Choices>
</QuestionPane>

<ExplanationPane>
<Explanation>
<SolutionStep number={1} title="Isolate the term with x">
Subtract $7$ from both sides: $3x = 22 - 7 = 15$.
</SolutionStep>

<SolutionStep number={2} title="Solve for x">
Divide both sides by $3$: $x = \frac{15}{3} = 5$.
</SolutionStep>
</Explanation>
