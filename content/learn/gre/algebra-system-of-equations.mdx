<Question>
If $2x + 3y = 12$ and $x - y = 1$, what is the value of $x + y$?
</Question>

<Choices answer="C">
<Choice label="A">3</Choice>
<Choice label="B">4</Choice>
<Choice label="C">5</Choice>
<Choice label="D">6</Choice>
<Choice label="E">7</Choice>
</Choices>
</QuestionPane>

<ExplanationPane>
<Explanation>
<SolutionStep number={1} title="Express x in terms of y">
From $x - y = 1$, we get $x = y + 1$.
</SolutionStep>

<SolutionStep number={2} title="Substitute into the first equation">
$2(y + 1) + 3y = 12$ simplifies to $2y + 2 + 3y = 12$, or $5y = 10$, so $y = 2$.
</SolutionStep>

<SolutionStep number={3} title="Find x and add">
Since $x = y + 1 = 3$, we get $x + y = 3 + 2 = 5$, choice **C**.
</SolutionStep>
</Explanation>
</ExplanationPane>
