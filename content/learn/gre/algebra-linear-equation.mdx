<Question>
If $3x - 7 = 2x + 8$, what is the value of $x$?
</Question>

<Choices answer="C">
<Choice label="A">1</Choice>
<Choice label="B">5</Choice>
<Choice label="C">15</Choice>
<Choice label="D">21</Choice>
<Choice label="E">-1</Choice>
</Choices>
</QuestionPane>

<ExplanationPane>
<Explanation>
<SolutionStep number={1} title="Move the variable terms to one side">
Subtract $2x$ from both sides: $3x - 2x - 7 = 8$, which simplifies to $x - 7 = 8$.
</SolutionStep>

<SolutionStep number={2} title="Isolate x">
Add 7 to both sides: $x = 8 + 7 = 15$.
</SolutionStep>

<SolutionStep number={3} title="Check the answer">
Substitute back in: $3(15) - 7 = 45 - 7 = 38$, and $2(15) + 8 = 30 + 8 = 38$. Both sides match, confirming $x = 15$, choice **C**.
</SolutionStep>
</Explanation>
</ExplanationPane>
</QuestionLayout>
