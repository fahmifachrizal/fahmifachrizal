# Deployment

## Build

The site is built as a static export using Next.js:

```bash
npm run build
```

This generates static HTML/CSS/JS in the `out/` directory.

## Hosting

Deployed via **Coolify** on a Hetzner Cloud instance. Pushes to `main` trigger an automatic deployment.

## Domain

- **Production**: `https://fahmifachrizal.com`
